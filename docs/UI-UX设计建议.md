# 标签编辑器 — UI/UX 设计建议（现代 Web 应用专家评审）

> 对标 Bartender 轻量版 / Canva / Figma 这类**设计型工具**的交互范式，而非普通后台表单。
> 核心原则：**编辑器是"所见即所得"的工作台，工具栏永远可见、画布永远可操作、属性面板只对被选中对象负责。**

---

## 一、整体布局：IDE 式四面包围 + 底部数据坞

需求里的"5 大区域"是正确的底座，但要收敛成**专业编辑器（IDE-like）**骨架，强调视觉层级与专注度。

```
┌─────────────────────────────────────────────────────────────┐
│  Top Bar  新建 │ 导入 │ 导出 │  ──  ── 打印 │ PNG │ PDF  缩放 │
├──────┬──────────────────────────────────────┬──────────────┤
│左工具箱│           居中 画布工作区（灰底）         │  右 属性面板   │
│ (icon)│       白色标签纸张（可缩放/平移/吸附）        │   纸张设置    │
│ 工具组 │                                      │  选中对象参数   │
│       │                                      │  文本/条码参数  │
├──────┴──────────────────────────────────────┴──────────────┤
│  Bottom Dock  数据文件│ 行跳转 ● 变量预览表格                    │
└─────────────────────────────────────────────────────────────┘
```

**布局建议：**
1. 用「可拖拽分隔条（resizable）」分隔左右面板与底部数据坞 → 贴合标尺/复杂标签的大屏工作场景。
2. 顶部栏与左/右/底三栏保持**固定高度**，仅中间画布区随窗口弹性伸缩 + 出现滚动条。
3. 左侧工具用**窄图标条（~64px）**，右侧属性面板可放宽（~300px），因为属性输入项多。
4. 桌面端优先；平板/小窗做响应式降级（工具收纳进抽屉）。

## 二、配色与视觉（契合 IDE 主题 light）

工具类编辑器采用**中性 + 单一品牌强调色**，避免五颜六色干扰"看标签本身"。

| 层 | 建议 |
|---|---|
| 背景（画布外） | `slate-100/gray-100` 高级灰，衬托白色纸面 |
| 画布纸张 | 纯白 `#fff`，加 1px 细边框 + 投影，模拟真实纸张 |
| 强调色（Primary） | 单一蓝 `#3b82f6` 或品牌色，用于选中框、主按钮、激活工具态 |
| 文字 | 深灰 `slate-900`；次级 `slate-500` |
| 危险操作 | 删除按钮红 `#ef4444`，仅在确认/悬停出现 |

**选中态反馈（关键）：**
- 被选中对象高亮 `primary` 控制柄 + 虚线边框；工具条对应工具项高亮同色。
- 统一使用 fabric.js 的默认选择框（`selectionColor`、`borderColor`），但覆盖成品牌色，避免刺眼黄绿。

## 三、交互范式建议（对齐设计工具标准）

### 1. 工具栏 —— "点一下即插入，自动选中"
- 点击「文本 / 条码 / 二维码 / 矩形 / 直线」→ **画布正中央生成默认元素并立即进入选中态**，属性面板同步回填 → 用户马上能看到"它就在那儿"。
- 上传图片用系统 file picker。
- 打印/导出类动作在顶部，作为"完成动作"统一视觉分组（或用 Separator 分隔）。

### 2. 画布区 —— 极重要
- **毫米单位系统**：`px = mm * 96 / 25.4`（DPI=96）。
- 右下角缩放滑块 + 百分比显示（50%–400%），支持滚轮缩放 / 空格拖拽平移。
- 网格 + 吸附对齐（`fabric` 用 `snapTolerance` / 磁性吸附），开启/关闭开关。
- 空白处点选 = 取消选择 → 属性面板回到"纸张设置"。
- 顶部可叠加毫米标尺（Ruler），对齐精修时极有用（二期）。

### 3. 属性面板 —— "选中才显示，改即所见"
- 分栏（Tabs/Sections）：`纸张` / `位置与尺寸` / `外观` / `内容`。
- 位置/尺寸输入带 **mm 后缀标签**，数字输入 `type=number` + 步进。
- X/Y/宽/高/旋转 → 输入框 blur 或 Enter 应用，避免拖动滑块时高频重排。
- 文本/条码内容支持 `{{字段名}}` → 面板内加 **字段提示下拉**（点选自动插入变量），大幅降低上手难度。
- 旋转：fabric 自带旋转手柄默认已满足，属性面板同步角度即可。

### 4. 底部数据坞 —— 变量驱动的核心
- 左：「上传 Excel/CSV」主按钮 + 文件名校验。
- 中：**行导航** `◀ 上一行 │ 第 N / M 行 │ 下一行 ▶`（配合大数据的行内切换）。
- 主体：可滚动表格，**点击行即"预览"该行数据 → 画布变量实时替换**，当前行高亮。
- 当画布无变量时提示"尚未使用 {{字段}} 变量"。

### 5. 打印 / 导出
- 先「渲染为高清图」再进入隐藏打印 DOM → 建议用 `@media print` 隐藏编辑界面，仅留打印稿。
- PNG 用高清倍率（如 2–3x）导出，避免模糊。
- PDF 用 jsPDF，按 mm 尺寸创建页面，像素清晰贴入。

## 四、反馈与错误处理

| 场景 | 反馈方式 |
|---|---|
| 导入 JSON 格式错误 | `sonner` toast 红提示 + 不破坏现有画布 |
| 上传非 Excel/CSV | toast 提示 + 拒绝 |
| 删除对象 | 直接删除 + toast 撤销（短期）或 Esc/右键删除 |
| 数据行为空 / 画布无变量 | 面板内空态文案 + 引导插图 |
| 所有输出动作成功 | 下载链接自动触发 + 成功 toast |

> 快捷键（MVP 加分）：`Delete` 删对象、`Ctrl+D` 复制、`Ctrl+Z/Y` 撤销重做、`+/-` 缩放。

## 五、组件化与状态模型（React 落地结构）

- **状态收敛到一处**：画布是"唯一事实源（fabric Canvas）"，React 只负责：
  - 工具选择、纸张尺寸、缩放比、当前预览行号、dataset。
  - 对象属性面板的值（由 selection 事件回填）。
- **双向绑定协议**：`对象变更事件 → 更新 React state`；`React 输入框变更 → fabric 对象 set()`。
- **避免 canvas 重渲染风暴**：用 `useRef` 持有 fabric 实例，绝不放进依赖数组。

```
components/
  editor/
    TopBar.tsx           工具栏按钮组 + 缩放
    Toolbox.tsx          左侧工具项
    CanvasStage.tsx      fabric 画布挂载 + 标尺 + 缩放
    PropertyPanel.tsx    右栏（纸张/位置/外观/内容）
    DataDock.tsx         底部数据表格 + 行导航
  ui/                    shadcn 基础组件
hooks/
  useCanvas.ts           初始化/销毁 fabric、暴露命令式 API
  useExport.ts           序列化/PNG/PDF/打印
types/
  template.ts            模板 JSON / dataset / 对象类型
```

## 六、落地优先级（分两期）

**MVP（本次交付）：**
1. 5 区布局 + fabric 画布 + 毫米系统 + 纸张尺寸可调
2. 文本/矩形/直线/条码/二维码/图片 添加与选中
3. 属性面板双向绑定（X/Y/宽/高/旋转/内容）
4. 数据导入（CSV/XLSX）→ 表格预览 → 变量替换
5. 模板 JSON 导入导出、PNG/PDF/打印

**二期可加：**
- 撤销/重做、多选对齐/分布、标尺网格吸附、图层/元素树、对象复制粘贴、字号/字体面板增强、变量一键铺版（自动排版）。

## 附：毫米换算速查（DPI=96）
| 换算 | 公式 |
|---|---|
| 像素 → 毫米 | `mm = px * 25.4 / 96` |
| 毫米 → 像素 | `px = mm * 96 / 25.4` |
| 默认纸 40×30mm | ≈ 151.2 × 113.4 px |

> 注：打印有边距偏移是浏览器/打印机特性，需用户在系统打印对话框选「无边距」，UI 文案应给出该引导。
